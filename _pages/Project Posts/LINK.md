LINK was created when I realized that I knew basically nothing about practical electronics and mechatronics and wanted to change that.

I love robotics so making a robotic manipulator seemed like a good crucible to forge an understanding of designing and implementing electromechanical systems. Now a way to control it. What better way to generate robotic arm inputs than by using a real human arm? All I knew is that it would be really awesome to see if I could pull it off...
